FIELD PILOT — ELECTRICAL PROJECT CONTROL
=========================================
This is a mobile-first installable PWA prototype.

Run locally:
1. Serve this folder over HTTP (service workers require localhost/HTTPS).
2. Open it on your phone.
3. Use the browser's "Add to Home Screen" / "Install app" action.

The app is currently a front-end prototype with local UI state and sample project data.
It includes the generated home-screen icon, mobile navigation, quick add, My Day,
projects, agenda calendar, task/contact forms, and responsibility/follow-up concepts.
